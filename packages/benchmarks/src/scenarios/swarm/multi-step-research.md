Research the best cloud platform for deploying a machine learning inference API. Consider:

**Researcher tasks:**
1. Compare AWS SageMaker, Google Vertex AI, and Azure ML for model deployment
2. Research pricing models for inference endpoints
3. Find latency benchmarks for each platform

**Analyst tasks:**
1. Analyze cost vs performance trade-offs
2. Evaluate integration with existing tools
3. Assess scalability and reliability

**Writer tasks:**
1. Synthesize findings into a report
2. Provide a clear recommendation with justification
3. Include a decision matrix

The final output should be a comprehensive recommendation report.
